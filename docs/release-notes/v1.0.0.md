# corx v1.0.0

First public release of `corx`, a self-hostable CORS proxy built with Bun.

## Highlights

- Ships a lightweight proxy service focused on simple deployment and predictable behavior.
- Forwards upstream request method and body to the target passed in the `url` query parameter.
- Adds CORS headers on all responses with configurable `Access-Control-Allow-Origin` via `ORIGIN_HOST`.
- Includes response-category allowlisting via `ALLOWED_RESPONSE_CATEGORIES`.
- Blocks disallowed upstream content types with `415` to reduce unintended proxy usage.

## Container Publishing

- Multi-arch Docker image published to GHCR:
  - `ghcr.io/venipa/corx:latest`
  - `ghcr.io/venipa/corx:v1.0.0`

## Runtime Configuration

- `PORT` (default: `3000`)
- `ORIGIN_HOST` (default: `*`)
- `ALLOWED_RESPONSE_CATEGORIES` (default: `json,xml,html,yml,text`)
  - Allowed categories: `json`, `xml`, `html`, `yml`, `text`, `image`, `video`, `audio`

## Quick Start

```bash
docker run --rm -p 3000:3000 ghcr.io/venipa/corx:v1.0.0
```

```bash
curl "http://localhost:3000/?url=https://example.com"
```
